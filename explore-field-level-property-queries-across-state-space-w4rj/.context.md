## Problem

Current analysis operates at object-version granularity (hashes). Sometimes you want to query field-level properties across the explored state space:

- "Find all states where Revision R1's Ready condition is True"
- "When did this annotation first appear?"
- "Which paths have this label set to X vs Y?"

This is hard because:
1. Objects are stored by hash, not by field index
2. Field-level diffing is expensive
3. Queries need to traverse the entire state DAG

## Exploration Areas

### Indexing Strategies
- Pre-compute field indexes during dump generation?
- Lazy indexing on first query?
- Which fields are worth indexing? (status conditions, labels, annotations)

### Query Language
- JSONPath-style queries? `$.status.conditions[?(@.type=='Ready')].status`
- Predicate functions in Go?
- SQL-like DSL?

### Efficient Representation
- Store normalized/flattened field paths alongside hashes?
- Delta-encode field changes between versions?
- Bloom filters for "does this state contain field X with value Y"?

## Use Cases

1. Condition propagation analysis: "trace how Ready=True propagates through the object graph"
2. Annotation/label tracking: "when did this finalizer get added?"
3. Spec drift detection: "did the spec change after initial creation?"

## Notes

This is exploratory - don't over-engineer. Start with concrete use cases and see what's actually needed.
