## Goal
Implement a Monte Carlo search mode that supports perturbation exploration for non-branch-safe controllers by running single-path sampled trials with process isolation, while preserving DFS-like catalog/inspector UX per scenario.

## Scope
- Add `SearchMode` + Monte Carlo config in explore/tracecheck config surfaces.
- Add random pending and stale-view selection strategies in `pkg/tracecheck/explore.go`.
- Keep Monte Carlo single-path (no branch fanout).
- Execute trials as process-isolated runs (`scenario x trial`).
- Add dump metadata + aggregation so TUI catalog presents grouped DFS-like scenario views.

## Design Reference
- `docs/design/monte-carlo-search-mode.md`

## Non-Goals
- Exhaustive interleaving guarantees in Monte Carlo mode.
- Adaptive/bias-driven sampling in v1.
- In-process cross-trial singleton reset hooks in v1.
