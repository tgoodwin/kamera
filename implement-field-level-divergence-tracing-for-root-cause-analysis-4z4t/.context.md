Current divergence detection finds ContentsHash LCA, but this can be misleading (false convergence with different pending lists).

New approach: trace differing fields backwards to find irreversible divergence.

Algorithm:
1. Compare terminal states, identify objects with different content
2. For each differing field (e.g., SKS.EndpointsPopulated), find when it was first set to its terminal value in each path
3. The earliest such point is where the 'permanent damage' occurred
4. This identifies the true root cause - the step that created an irreversible condition

Benefits:
- Focuses on what actually matters (fields that differ at terminals)
- Finds when the outcome became inevitable, not just when paths split
- Handles both false convergence (ContentsHash DAG) and false divergence (StateHash DAG) issues
