Audit and formalize the baseline trace contract required by checkpoint scanning.

Current code already captures rich per-step data (state before/after, effects, pending set, mutation history). This task should:
1) document exactly which existing fields are available and sufficient for scanner predicates,
2) define the minimal trace contract the scanner depends on,
3) add trace fields only if a concrete scanner requirement is truly missing,
4) add focused tests to prevent regressions in trace contents relied upon by scanner logic.

Goal: avoid redoing tracing infrastructure; target only real gaps.
