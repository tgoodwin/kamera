A composable framework for analyzing divergence in kamera dump files, using backward-trace methodology.

## Design Philosophy

Start from known divergence (final state differences) and trace backwards to root cause. This avoids noise from 'diamond' patterns where paths diverge then reconverge.

## Architecture

Three composable modules in pkg/analysis/:

**Module 0: Converged State Diff** (kamera-pwm)
- Input: dump.jsonl
- Output: Objects that differ between converged states
- Answers: 'In what ways do the final states differ?'

**Module 1: Last Write Analysis** (new task)
- Input: dump.jsonl + differing object keys
- Output: For each object+path, the step that produced its final value + reconciler's input state
- Answers: 'What did the reconciler see when it wrote this value?'

**Module 2: Object Lifecycle Analysis** (kamera-gwc)
- Input: dump.jsonl + path + object + target hash
- Output: All steps where object had that hash
- Answers: 'Does this object take on this value at some point in this path?'

## Composition Flow

1. Run Module 0 to identify differing objects
2. Run Module 1 on each differing object to find last writes and input diffs
3. If inputs differ, run Module 2 to check 'does the missing state appear later?'
4. If yes, points to watch/trigger issue; if no, points to state dependency

## Package Structure

pkg/analysis/
├── types.go      # Shared types (moved from pkg/interactive)
├── dump.go       # Dump loading utilities  
├── diff.go       # Module 0
├── lastwrite.go  # Module 1
├── lifecycle.go  # Module 2
