Root cause analysis requires efficiently finding all steps where a field has a particular value.

Current approach: ad-hoc jq queries over dump file - slow and cumbersome.

Desired: Index that maps (Kind, field-path, value) -> list of (path, step) coordinates.

Example queries this would enable:
- 'Find all steps where Endpoints.subsets has >0 items'
- 'Find all steps where SKS.EndpointsPopulated=Unknown'
- 'Find when Revision.status.conditions[Active] was first set'

Could be computed when loading dump and stored in memory, or pre-computed and stored in dump file.
