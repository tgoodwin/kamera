**Forward-trace divergence point finder (separate from backward-trace framework)**

This tool answers: 'Where do paths first diverge?' - a forward-trace question.

Note: The backward-trace framework (kamera-7tl) starts from final state differences and traces backwards. This tool takes the opposite approach - finding where paths first diverge and tracing forward.

Forward-trace can produce noise due to 'diamond' patterns (diverge then reconverge), but is still useful for:
- Quick identification of initial divergence point
- Understanding early cascade effects
- Debugging reconciler ordering issues

## Algorithm
1. Compare stateBefore/stateAfter across paths at each step index
2. Find first step where stateAfter differs between any two paths
3. Report the controller and effects at that step

## Relationship to Backward-Trace Framework
- Use backward-trace (kamera-7tl) for root cause analysis of final state differences
- Use this tool for quick forward exploration of 'what happens after step N diverges'

## Original Description
Build a tool that finds the first step where execution paths diverge:
- Compare stateBefore/stateAfter across paths
- Identify the exact step number and controller where divergence starts
- Show what changed differently (effects produced)
- Report whether paths started from identical state
