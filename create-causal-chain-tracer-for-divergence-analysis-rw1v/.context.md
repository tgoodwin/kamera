## Original Description (preserved)
Build a tool that traces how an initial divergence cascades to final state differences:
- Given a divergence point, track how the difference propagates
- Show which reconcilers are affected by the divergence
- Identify when/if paths reconverge on specific objects
- Produce a summary showing: initial cause -> intermediate effects -> final outcome
