**Unified CLI for divergence analysis (depends on kamera-7tl modules)**

Consolidate all dump analysis tools into a single CLI with subcommands:

```
kamera-analyze diff <dump.jsonl>              # Module 0: Converged state differences
kamera-analyze lastwrite <dump.jsonl>         # Module 1: Last write analysis  
kamera-analyze lifecycle <dump.jsonl> [opts]  # Module 2: Object lifecycle
kamera-analyze diverge <dump.jsonl>           # Forward-trace divergence finder
kamera-analyze report <dump.jsonl>            # Full backward-trace analysis
```

The `report` subcommand composes Modules 0→1→2 and produces a complete analysis.

## Output Formats
- Terminal (default): Human-readable colored output
- JSON (`--json`): Structured output for composition
- Markdown (`--md`): For inclusion in analysis docs

## Location
Could be cmd/kamera-analyze/ or integrated into existing kamera binary.
