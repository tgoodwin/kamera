Redesign the coverage/input generation pipeline from a fully-static approach to an execution-guided (closed-loop) approach. See docs/design/coverage-strategy-v2.md.

Key direction:
1) seeds are generated from explicitly marked user-facing resource types,
2) perturbation profiles are inferred from static dependency graph patterns,
3) each seed gets a deterministic baseline execution,
4) baseline traces are scanned for profile-relevant checkpoints,
5) branching exploration resumes from checkpoints with perturbations applied.

Important constraints for this epic:
- Input-generation logic should consume an explicit graph/schema contract (including resource-role metadata) instead of relying on fragile heuristics.
- Existing determinization/normalization and existing trace richness should be treated as baseline capabilities and reused.
- Legacy pre-fabricated coverage.Input/scenario conversion paths should be retired after the new closed-loop entrypoint is in place.
